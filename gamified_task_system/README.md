# Hardcore Gamified Task Evaluator

A multilingual, Streamlit-based web application that gamifies your daily to-do lists and goals.

## Features
- **Goal Tracking & Prioritization:** Create tasks and use the AI Advisor to sort their priority.
- **Leveling System:** Earn EXP by completing tasks and level up from Novice to Legend.
- **AI Evaluator:** Submit your daily actions and the Gemini AI will objectively evaluate your progress contribution.
- **Multilingual:** Full support for English, Chinese, and Thai.

## Setup
1. Clone this repository.
2. Install the required packages: `pip install -r requirements.txt`
3. Launch the application:
   - **Mac:** Double-click `run.command`
   - **Windows:** Double-click `run.bat`
   - **Terminal:** Run `python -m streamlit run gamified_task_app.py`
